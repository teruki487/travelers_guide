# 仮デザインモック 0.2

[travelers-guide.html](travelers-guide.html) をダウンロードし、Chrome等のブラウザーで開いてください。単独ファイルで動作し、サーバー・ライブラリのインストールは不要です。GitHub上のファイル表示はソース表示であり、操作プレビューではありません。

## 確認手順

1. 上部のレビュー用バーで「幹事／参加者」を切り替える。参加者では共有情報の編集ボタンを表示しない。
2. 「PC／スマートフォン」を切り替え、日程・持ち物・お知らせ・メンバー・変更通知の各画面を確認する。
3. 「変更を受信（デモ）」を押すと、集合時刻が09:30になり、変更通知と未読数が更新される。
4. 持ち物をチェックすると、自分の準備数が変わる。
5. 幹事画面の「編集」で保存・キャンセル、競合・通信失敗時の入力保持を確認する。
6. 状態を「接続切断」にし、「再接続する（デモ）」で最新情報取得の表示を見る。
7. 状態を「リンク失効」にすると旅行本文を隠し、再共有依頼の案内を表示する。
8. 「共有リンク」で参加者専用リンクと取り扱い説明を見る。表示URLは無効なサンプル。
9. 「変更通知」で通知設定の説明、未読→既読、更新内容への移動を確認する。
10. PC表示の「旅行一覧へ」から一覧と新規作成ダイアログを確認する。

## 範囲と制約

これは基本設計の見た目・導線・状態のモックです。すべて架空の情報で、本番データではありません。

- 予定編集は代表例として集合予定を扱う簡易デモです。日程の全件CRUDではありません。
- 持ち物・お知らせ・参加者の追加は入力領域の構成案のみで、登録しません。
- 新規作成はタイトルの表示反映だけを行い、旅行や権限を発行しません。
- 再読込すると初期状態に戻ります。DB・ブラウザーへの永続保存はしません。
- 通信、実際のリアルタイム配信、権限検証、秘密リンク生成、OS通知、クリップボード操作は実施しません。
- 印刷/JSON出力、リンク再発行・解除、参加入口の細かな部品は基本設計本文の対象ですが、今回のモックでは未作成です。
- モックのロール切替はレビュー専用であり、製品に自由な権限切替を設けるものではありません。
